# Since 1958

NASA Space Apps Challenge 2026 · Challenge: *Abandoned but not Forgotten* · Team Concinendial

An interactive 3D solar system that shows the hardware left on the Moon and Mars and the probes that never came home: watch each one arrive, see the day it fell silent, and walk to where it rests today.

Open `index.html` through any static web server (it uses ES modules, so it will not run from `file://`).
